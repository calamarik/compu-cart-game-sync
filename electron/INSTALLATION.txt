COMPU-CART 1.2 — WINDOWS x64 — GUIDE D'INSTALLATION ET D'UTILISATION
=====================================================================

1. INSTALLATION
---------------
Configuration : Windows 10 ou Windows 11, processeur Intel/AMD 64 bits.
Pas besoin de Node.js, d'Electron, d'un compte, d'Internet ni des droits
administrateur : l'installation se fait pour votre compte Windows.

1) Double-cliquez sur Compu-Cart-Setup-1.2.0.exe.
2) Choisissez les options :
   - « Démarrer avec Windows (en arrière-plan) » : coché par défaut.
     Compu-Cart s'ouvre discrètement à chaque ouverture de session et attend
     une cartouche depuis la zone de notification (près de l'horloge).
   - « Raccourci sur le Bureau » : facultatif.
3) Gardez le dossier proposé (%LOCALAPPDATA%\Programs\Compu-Cart) ou
   choisissez-en un autre, puis cliquez sur « Installer ».
4) Cochez « Lancer Compu-Cart maintenant » pour terminer.

Le programme apparaît dans le menu Démarrer (dossier Compu-Cart), avec le
guide et la désinstallation. Si Compu-Cart était ouvert, l'installation le
ferme : terminez d'abord votre partie.

L'installateur n'est pas signé : Windows SmartScreen peut afficher
« Windows a protégé votre ordinateur ». Vérifiez l'origine du fichier, puis
« Informations complémentaires » → « Exécuter quand même » si vous lui
faites confiance. Ne désactivez pas l'antivirus. Une politique d'entreprise
peut interdire les programmes non signés.

Mise à jour depuis la version 1.0 portable : lancez simplement l'installateur.
Vous pouvez ensuite supprimer l'ancien dossier Compu-Cart-win32-x64 ; vos
sauvegardes (%APPDATA%\CompuCart) ne sont pas touchées.

2. FONCTIONNEMENT EN ARRIERE-PLAN
---------------------------------
Compu-Cart vit dans la zone de notification (icône cartouche orange près de
l'horloge ; cliquez sur la flèche ^ si elle est masquée).
- Clic sur l'icône : afficher Compu-Cart.
- Clic droit : Afficher, Jouer (quand une cartouche est prête), Éjecter la
  cartouche, Démarrer avec Windows (activer/désactiver), Quitter.
- Le bouton « Réduire » de l'écran Compu-Cart le renvoie en arrière-plan.
  Fermer la fenêtre (Alt+F4) fait de même ; pour l'arrêter complètement,
  utilisez « Quitter ».

Détection : Compu-Cart n'interroge plus les lecteurs en boucle. Il attend le
signal que Windows envoie lorsqu'une clé USB est branchée ou retirée, puis
vérifie les lecteurs D: à Z: quelques fois pendant 4 secondes. Le reste du
temps, il ne consomme pratiquement rien.

Cartouche déjà branchée au démarrage : à l'ouverture de Compu-Cart (ou de
votre session Windows), il cherche tout de suite une cartouche déjà présente,
puis encore après 2, 6 et 15 secondes, le temps que Windows reconnaisse la clé.
Dans ce cas, Compu-Cart vérifie et synchronise la cartouche mais ne lance PAS
le jeu tout seul : elle passe sur « Prête ». Si Compu-Cart est en arrière-plan,
une bulle « Cartouche prête » apparaît près de l'horloge ; cliquez dessus pour
afficher Compu-Cart. Le bouton « ▶ Jouer » (écran ou menu de l'icône) lance
alors l'intro puis le jeu.
Seule une cartouche branchée pendant que Compu-Cart tourne lance son jeu
automatiquement. Le bouton « ▶ Jouer » sert aussi à relancer le jeu après
l'avoir quitté.

Plein écran : dès qu'une cartouche est branchée, Compu-Cart passe en plein
écran sans bordure et masque le Bureau. Pendant le jeu, il reste en fond noir
derrière lui : si le jeu change la résolution de l'écran, vous ne voyez pas
le Bureau. À la fermeture du jeu, Compu-Cart revient au premier plan.

3. EJECTER LA CARTOUCHE SANS RISQUE
-----------------------------------
Utilisez le bouton « ⏏ Éjecter » de l'écran Compu-Cart, ou « Éjecter la
cartouche » dans le menu de l'icône. Il est disponible quand aucun jeu ni
synchronisation n'est en cours.
Compu-Cart écrit les données en attente, verrouille le support, le démonte,
puis demande à Windows de le déconnecter (comme « Retirer le périphérique
en toute sécurité »).
- « Vous pouvez retirer la cartouche en toute sécurité » : retirez-la.
- « Un programme utilise encore la cartouche » : fermez l'Explorateur ou le
  programme ouvert sur la clé, puis réessayez. Ne retirez pas la clé.
- « Données écrites et volume démonté, mais Windows n'a pas déconnecté le
  périphérique » : les données sont écrites ; vous pouvez retirer la clé si
  aucun autre programme ne l'utilise.
Si la cartouche est quand même retirée sans éjection, les sauvegardes locales
sont conservées et la synchronisation reprendra au prochain branchement.

Après une éjection, la cartouche n'est plus surveillée, même si elle est
encore branchée. Pour la retrouver sans la débrancher, cliquez sur
« 🔍 Rechercher » (ou « Rechercher une cartouche » dans le menu de l'icône).
Compu-Cart cherche les lecteurs D: à Z:, puis demande à Windows de relancer sa
détection du matériel et cherche encore. Une cartouche retrouvée ainsi passe
sur « Prête » : cliquez sur « ▶ Jouer » pour lancer le jeu.
Cette recherche n'a lieu que quand vous cliquez. Si Windows ne remet pas la
clé à disposition (c'est possible après une éjection complète, et la relance
de la détection peut demander les droits administrateur), le Journal l'indique :
débranchez alors la clé puis rebranchez-la.

4. PREPARER UNE CARTOUCHE
-------------------------
Utilisez uniquement un support et un jeu de confiance dont vous avez les droits.
Le jeu doit pouvoir être lancé directement : ses propres dépendances,
licences, pilotes ou installateurs ne sont pas inclus.
Aucun jeu n'est fourni. Le dossier exemple-cartouche (dans le dossier
d'installation) contient seulement un modèle de manifeste.

Exemple de structure de votre clé USB (lettre E: donnée à titre d'exemple) :
  E:\compucart.json
  E:\bin\MonJeu.exe
  E:\saves\
  E:\intro.png       (facultatif)
  E:\jingle.mp3      (facultatif)

Après avoir copié un jeu portable sur la clé, ouvrez Windows PowerShell dans
le dossier d'installation (%LOCALAPPDATA%\Programs\Compu-Cart) et lancez :

  powershell.exe -NoProfile -File ".\outils\Preparer-Cartouche.ps1" -Racine "E:\" -Id "mon-jeu" -Titre "Mon jeu" -Executable "bin\MonJeu.exe"

Remplacez E:, l'identifiant, le titre et le chemin par vos valeurs réelles.
L'outil crée compucart.json, l'empreinte de l'exécutable et le dossier saves.
Si votre politique PowerShell bloque les scripts, utilisez la méthode
manuelle ci-dessous plutôt que de modifier votre politique de sécurité.

Méthode manuelle : calculez l'empreinte avec :
  Get-FileHash "E:\bin\MonJeu.exe" -Algorithm SHA256
Copiez exemple-cartouche\compucart.modele.json vers E:\compucart.json,
remplacez tous les champs et le marqueur d'empreinte par votre valeur SHA-256
de 64 caractères (0-9 et a-f, sans espace). Enregistrez le JSON en UTF-8.
Chaque chemin de checksums doit correspondre exactement au fichier.
Pour vérifier aussi les données du jeu, ajoutez leurs chemins et empreintes
à checksums. La vérification ne porte que sur les fichiers listés.

Pour une intro personnalisée, remplacez intro:{} dans le manifeste par :
  "intro": { "image": "intro.png", "audio": "jingle.mp3" }
Utilisez une image PNG et un son MP3. Sans ces fichiers, l'intro Compu-Cart
et son jingle sont joués. Le jeu est lancé automatiquement après 3,2 secondes
(au branchement, ou quand vous cliquez sur « ▶ Jouer »).
Les chemins sont relatifs à la clé ; les liens et chemins sortant du support
ne sont pas autorisés. Les SHA-256 détectent les modifications, mais ne
prouvent pas qu'un jeu est sûr : ils ne remplacent pas un antivirus.

5. SAUVEGARDES
--------------
Le dossier local est créé automatiquement ici :
  %APPDATA%\CompuCart\saves\<id>
Configurez le jeu pour écrire et lire ses sauvegardes dans ce dossier ;
Compu-Cart ne redirige pas automatiquement les sauvegardes d'un jeu.

Au branchement puis à la fermeture du jeu, la version la plus récente de
chaque fichier gagne, avec une tolérance de 2 secondes. Un fichier manquant
est copié ; les suppressions ne sont pas répliquées. Il n'y a pas de fusion
de deux parties. Chaque copie passe par un fichier temporaire vérifié
SHA-256 ; l'ancienne version est conservée en .bak.
Le jeu doit rester lié au processus lancé : les lanceurs qui quittent avant
le vrai jeu ne permettent pas de détecter correctement sa fin.

6. DEPANNAGE ET DESINSTALLATION
-------------------------------
« Empreinte SHA-256 invalide » : la valeur dans checksums n'a pas 64
caractères hexadécimaux (marqueur du modèle non remplacé, espace en trop…).
« Intégrité compromise » : un fichier ne correspond plus à son empreinte.
Rien ne se passe au branchement : vérifiez que compucart.json est à la racine
de la clé et que Compu-Cart tourne (icône près de l'horloge).
La cartouche est branchée mais le jeu ne démarre pas : si elle était déjà là au
démarrage de Compu-Cart, c'est normal. Cliquez sur « ▶ Jouer ». Si l'état
« Prête » n'apparaît pas, ouvrez Compu-Cart depuis l'icône : le Journal indique
ce qui a été détecté.
Le jeu s'ouvre derrière Compu-Cart : cliquez sur le jeu dans la barre des
tâches (Alt+Tab).

Désinstaller : Paramètres Windows → Applications → Compu-Cart →
Désinstaller (ou menu Démarrer → Compu-Cart → Désinstaller Compu-Cart).
Le démarrage automatique est retiré. Vos sauvegardes dans %APPDATA%\CompuCart
sont conservées ; supprimez ce dossier vous-même si vous voulez les effacer.

7. VALIDATION DE CETTE LIVRAISON
--------------------------------
Les règles de détection, d'éjection et de synchronisation ont passé leurs
tests automatiques, et le code d'éjection Windows a été compilé sans erreur.
Le programme Windows, le branchement USB réel, l'éjection réelle et le
lancement d'un vrai jeu n'ont pas pu être essayés sur un ordinateur Windows
dans cet environnement de fabrication. C'est aussi le cas de la version 1.2 :
la détection d'une cartouche déjà branchée au démarrage, l'état « Prête », le
bouton « Jouer » et la bulle de notification n'ont été validés que par des
tests automatiques (détection simulée, règles de démarrage, état de la console).
